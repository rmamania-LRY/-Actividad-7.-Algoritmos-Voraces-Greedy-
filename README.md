# -Actividad-7.-Algoritmos-Voraces-Greedy-

Repositorio que contiene las soluciones implementadas en **C++** para los problemas de optimización utilizando la estrategia voraz (Greedy).

## 📂 Contenido del Proyecto
- Mochila_Fraccional: Solución basada en el criterio de densidad de valor 
- Cobertura_de_Antenas: Solución basada en la colocación de antenas con radio de cobertura mínimo sobre una línea recta.

## ⚙️ Requisitos
- Un compilador de C++.
